FrictionLayer

Sites below show a countdown before they load.

FrictionLayer needs permission to access websites to intercept them.

Sites

    Subdomains are included (reddit.com also covers old.reddit.com).

    Countdown

    Set to 0 to wait again on every page load (including new tabs). The countdown only runs while the tab is visible.

    Escalating timers

    Counted per site, resets at local midnight. A site's first open uses the default countdown.
